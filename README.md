# 🎙️ Key Notes & Presentations

> Compartilhando conhecimento em Inteligência Artificial, Engenharia de Software, Java, Arquitetura e Cloud.

## 📑 Visão Geral

Este repositório foi estruturado para facilitar o **acesso, download e compartilhamento** de apresentações técnicas realizadas em conferências, meetups, workshops e treinamentos.

As apresentações estão disponíveis em diversos formatos:
- 🍏 **Apple Keynote** (`.key`): Formato nativo com animações e layout de alta fidelidade.
- 📊 **Microsoft PowerPoint / Google Slides** (`.pptx` / `.ppt`): Padrão multiplataforma.
- 🌐 **Web / HTML** (`.html`): Apresentações navegáveis diretamente no browser (Reveal.js, Marp, Slidev).
- 📄 **PDF** (`.pdf`): Visualização rápida e leitura direta pelo GitHub.

## 🚀 Como Visualizar e Compartilhar

1. **Visualização Rápida no Navegador**: Arquivos `.pdf` e `.html` podem ser abertos diretamente pelo navegador ou pelo visualizador do GitHub.
2. **Download dos Slides Originais**: Clique no link do formato desejado (`.key` ou `.pptx`) e utilize o botão **Download** do GitHub.
3. **Apresentações Web (HTML)**: Podem ser hospedadas via GitHub Pages ou abertas localmente dando um duplo clique no arquivo `index.html`.
