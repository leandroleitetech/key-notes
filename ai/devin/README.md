## 🎮 Controles e Navegação

Esta apresentação foi construída com suporte completo para navegação fluida em palco, meetups virtuais e controle remoto (passador de slides):

| Ação | Teclas & Atalhos | Controle / Passador |
| :--- | :--- | :--- |
| **Próximo Slide** | `→` (Seta Direita), `↓`, `Espaço`, `Enter`, `N` | Botão Avançar / `PageDown` |
| **Slide Anterior** | `←` (Seta Esquerda), `↑`, `Backspace`, `P` | Botão Voltar / `PageUp` |
| **Modo Claro / Escuro** | `T` | Botão Tema no topo |
| **Primeiro / Último** | `Home` / `End` | — |
| **Tela Cheia** | `F` | Botão Apresentar / `F5` |
| **Notas do Orador** | `S` | Abre gaveta de anotações do apresentador |
| **Visão Geral (Grid)** | `O` ou `Esc` | Abre grade com todos os slides para salto rápido |
| **Black / White Screen** | `B` (Tela Preta) / `W` (Tela Branca) | Botão Blackout do passador |
| **Dispositivos Móveis** | Deslizar (*Swipe*) para a esquerda/direita | — |
